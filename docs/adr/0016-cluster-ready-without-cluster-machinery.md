# ADR-0016 — Cluster-ready without cluster machinery.

*Context:* Multi-node operation (placement, failover, gossip) is post-MVP, but a design that assumes one process needs a rewrite to get there. *Decision:* Ship five inert seams and forbid code that bypasses them. (1) **Cell identity** is `sha256(key)` and placement is a pure function of it, so any node can compute where a cell belongs. (2) **Cell directories are self-contained and relocatable** — no absolute paths, no references outside the directory; a cell is `db.sqlite` + `meta.json` + its blob pin. (3) **Blobs are content-addressed**, so two nodes can share or fetch them without coordination. (4) **All resolution goes through `Locator.resolve(key) → Placement{local | remote(addr)}`**; the MVP returns `local` always, and the HTTP layer already answers a `remote` with `307`. (5) **`meta.json` carries `owner_node` and `epoch`** from the first write, though both stay constant until a cluster exists. *Consequences:* Cluster mode becomes policy plus a gossip/lease implementation, not a data-model migration; the cost is one indirection per request and two metadata fields. `gates/check-locator.sh` fails any file outside `runtime/` that reaches a cell by key without the locator.

_Status: accepted. Immutable; supersede rather than edit._
